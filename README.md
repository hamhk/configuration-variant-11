# Конфигурационное управление · вариант 11

Утилита читает учебный конфигурационный язык из стандартного ввода,
вычисляет константные выражения и записывает результат в JSON.
Для синтаксического разбора используется Lark с отдельной LALR-грамматикой.

## Установка и тесты

Требуется Python 3.10 или новее. Отдельный этап сборки не нужен.
Выполните команды из корня проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## Запуск

Ключ `-o` или `--output` задаёт путь к JSON-файлу. Ключ `--help` выводит
справку. Ввод и вывод используют UTF-8, при вводе допускается BOM.
При ошибке утилита выводит диагностику в stderr и возвращает код 1.
При синтаксической ошибке указываются строка и столбец.

```powershell
cmd /c "run.bat -o library.json < examples\library.cfg"
cmd /c "run.bat --output greenhouse.json < examples\greenhouse.cfg"
```

Первый пример описывает библиотеку, её отделы и итоговое число мест.
Второй задаёт диапазон температур теплицы и список датчиков.

```json
["Городская библиотека", [2, ["Абонемент", "Читальный зал"]], 32]
```

```json
["Теплица", [23, 29], [3, ["температура", "влажность", "свет"]]]
```

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Однострочный комментарий | `' комментарий` |
| Шестнадцатеричное целое | `0x2a` или `0X2A` |
| Строка | `[[текст]]` |
| Пустой или вложенный массив | `list(0x2, list())` |
| Объявление константы | `const size = 0x10` |
| Ссылка на константу в выражении | `$size$` |
| Сложение и вычитание целых | `$size + (3 - 1)$` |
| Длина строки или массива | `$len([[текст]])$` |

Имена состоят из строчных латинских букв. Константы объявляются до
использования. Повторное объявление считается ошибкой.
Выражения допускают десятичные целые, как в примере из задания.
Операции `+` и `-` имеют одинаковый приоритет и выполняются слева направо.
Скобки позволяют изменить порядок. `len()` возвращает число символов
строки или число элементов массива.

Документ содержит объявления и, при необходимости, одно итоговое
значение. Если итоговое значение есть, оно становится корнем JSON.
Документ из одних объявлений превращается в объект с этими константами,
а пустой документ даёт `{}`. В задании формат корня не задан, поэтому
это соглашение выбрано для данной реализации.
