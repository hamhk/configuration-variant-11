# Конфигурационное управление · вариант 11

Утилита читает конфигурацию из стандартного ввода, вычисляет константные
выражения и записывает результат в JSON-файл. Синтаксис описан в
[грамматике Lark](src/grammar.lark). Разбор, вычисление и запись
результата запускаются через [src/main.py](src/main.py).

## 1. Подготовка

Нужны Git и Python 3.10 или новее. Если проект ещё не скачан, выполни
в PowerShell:

```powershell
git clone https://github.com/hamhk/configuration-variant-11.git
cd configuration-variant-11
```

Остальные команды выполняй из корня проекта. Окружение создаётся один раз.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
New-Item -ItemType Directory -Force out | Out-Null
.\run.bat --help
```

Ключ `-o` или `--output` задаёт путь к JSON-файлу. Ключ `--help` выводит
справку. Ввод и вывод используют UTF-8. В командах ниже `cmd /c`
передаёт исходный файл в стандартный ввод через `<`.

## 2. Пример с библиотекой

Сначала покажи [исходную конфигурацию](examples/library.cfg), затем
открой полученный JSON.

```powershell
Get-Content examples\library.cfg -Encoding utf8
cmd /c "run.bat -o out\library.json < examples\library.cfg"
Get-Content out\library.json -Encoding utf8
```

Ожидаемый результат в компактной записи.

```json
["Городская библиотека", [2, ["Абонемент", "Читальный зал"]], 32]
```

`$len(rooms)$` даёт два отдела, `$rooms$` подставляет их список,
а `$seats + 8$` даёт 32 места, потому что `0x18` равно 24.

## 3. Пример с теплицей

Покажи [исходную конфигурацию](examples/greenhouse.cfg), затем
открой полученный JSON.

```powershell
Get-Content examples\greenhouse.cfg -Encoding utf8
cmd /c "run.bat --output out\greenhouse.json < examples\greenhouse.cfg"
Get-Content out\greenhouse.json -Encoding utf8
```

Ожидаемый результат в компактной записи.

```json
["Теплица", [23, 29], [3, ["температура", "влажность", "свет"]]]
```

Целевая температура `0X1A` равна 26, а допуск `0x03` равен 3.
Два выражения дают границы 23 и 29, а `$len(sensors)$` считает три датчика.

## 4. Демонстрация синтаксической ошибки

В этом вводе пропущена запятая между элементами массива.

```powershell
'list(0x1 0x2)' | .\run.bat -o out\invalid.json
$LASTEXITCODE
```

Ожидай сообщение «Синтаксическая ошибка» в строке 1, указатель на
проблемный участок и код выхода `1`. При такой ошибке утилита
завершает работу до записи выходного файла.

## 5. Автоматические тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Ожидай `Ran 7 tests` и `OK`. Тесты проверяют литералы, вложенные массивы,
вычисление констант, ошибки и запуск обоих примеров через CLI.

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Однострочный комментарий | `' комментарий` |
| Шестнадцатеричное целое | `0x2a` или `0X2A` |
| Строка | `[[текст]]` |
| Пустой или вложенный массив | `list(0x2, list())` |
| Объявление константы | `const size = 0x10` |
| Ссылка на константу в выражении | `$size$` |
| Сложение и вычитание целых | `$size + (3 - 1)$` |
| Длина строки или массива | `$len([[текст]])$` |

Имена состоят из строчных латинских букв. Константы объявляются до
использования. Повторное объявление считается ошибкой.
В выражениях допускаются десятичные целые, как в примере из задания.
Операции `+` и `-` имеют одинаковый приоритет и выполняются слева направо.
Скобки позволяют изменить порядок. `len()` возвращает число символов
строки или число элементов массива.

Документ содержит объявления и, при необходимости, одно итоговое
значение. Если итоговое значение есть, оно становится корнем JSON.
Документ из одних объявлений превращается в объект с этими константами,
а пустой документ даёт `{}`. Это соглашение реализации, поскольку
условие не задаёт формат корня JSON.
